# 深渊天平引擎 · 互动叙事项目

Android / Pydroid3 本地互动叙事项目。正式入口支持逐节点演播、自动语音、段末抉择、体力结算、游戏时间、随机序幕及分层记忆。

## 运行

在项目目录安装 Python 依赖 Flask、requests，以及使用对应语音后端需要的依赖，然后运行 `语音运行.py`。规则入口见 `AGENTS.md`；开发计划及验收记录在 `scene_chat_dev/`。

仓库中的语音服务密钥从环境变量 `FISH_API_KEY` 读取。启动前在自己的运行环境设置该变量；密钥不要提交。原设备的本地文件保留原设置，首次提交仅对 Git 暂存内容脱敏，因此本地 `语音运行.py` 与仓库版本存在预期差异。
