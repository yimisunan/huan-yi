## 当前行为

### 配置

读取配置不再创建文件或保存清洗结果。导入模块也不会触发配置重写。首次直接启动且配置确实不存在时，由初始化函数创建默认配置。

读取失败或结构异常时，GET 配置接口返回 503；对损坏配置的保存返回 409 并保留原文件，避免把错误读取结果覆盖成默认值。空请求、非法角色配置返回 400。写入使用同目录临时文件、flush/fsync 与原子替换；替换失败时保留原文件并清理临时文件。

已有角色及 settings 的未知扩展字段予以保留；明确淘汰的旧供应商参数继续清除，长期 emotion 继续清空。

### 语音

两页统一使用 65 秒客户端等待窗口。Fish 请求连接超时 8 秒、读取空闲超时 45 秒；Edge 整条合成及候选回退使用 45 秒总等待上限。这里的 Fish 读取超时不是整个 HTTP 响应的绝对墙钟时间上限。

后端最多同时生成 2 条语音。相同文本、音色、模型、参数的请求共用进行中的任务，成功结果可直接复用。失败不进入缓存，允许稍后重试。内存缓存淘汰阈值为 64 条、32 MiB，成功结果保留最长 6 小时；重启服务会清空缓存。

客户端跳过等待、切换内容或关闭声音后，不再把旧结果落到新节点。取消浏览器 fetch 不能承诺撤销已送达供应商的生成或收费；后端任务可能继续完成，结果供相同请求复用。没有加入自动重试付费生成。

正文页音频 URL 按 24 条、24 MiB 阈值淘汰，保留当前播放与刚创建的资源，重新装载内容和离开页面时全部释放。当前或刚创建的单条超大音频可暂时超过阈值，不能把这个阈值视为整个浏览器的绝对内存上限。调音台只保留最近一次试听音频。

### 安卓操作

管理页先显示本地配置，远程音色列表独立加载。列表失败时仍能编辑及保存本地配置；余额查询改为用户主动点击，避免初始化时额外等待。

后台列表更新与角色切换保留文本草稿。保存成功后更新已保存快照；保存失败仍标记未保存。提交过程中继续修改时保留新修改，不以旧响应覆盖。离开有未保存修改的页面时使用浏览器原生提醒，该提醒是否出现受浏览器限制。

试听生成中再次点击会跳过当前等待，之后可重新试听。音频已生成但自动播放被浏览器拦截时，提示使用播放器手动播放，保留下载入口。

管理页按钮最低 48 CSS px 高，音色候选删除按钮 48×48 CSS px；CSS px 与安卓原生 dp 是不同单位。按钮间距、输入行换行、表单最小宽度和底部安全区一并调整。

### 文件访问

默认监听 `127.0.0.1:5000`。仍使用原来的手机本机访问地址；其他设备通过局域网地址访问将不再可用。

HTTP 静态读取仅允许两张运行页面、共用脚本、运行快照、前端实际使用的两份存档，以及 `txt文件/image/` 图片。源码、配置原文件、规则、开发目录和备份不再直接返回。配置接口仍按原路径提供清洗后的配置供页面使用。
