# 项目文件清理与维护入口

当前应用的维护入口见 [开发者说明书 §2.1](../../../../开发者说明书/开发者说明书.md)。所有当前源码保持原路径；本轮只整理文件、维护文档和同步/检索排除项。

已将140份 `.into-backup-*` 移到 `开发者功能/归档/项目清理/历史修改备份/`，并保留原相对目录及文件名。本轮说明书与同步配置的2份父版也在该区。归档仅供追溯、恢复，不应作为当前应用代码继续修改。

4份用途待确认资料收在 `开发者功能/归档/项目清理/用途待确认/开发者功能/开发者工具/`：`破甲.md`、`音频截取工具.html`，以及`视频转图片工具/`中的2份说明。它们不在当前服务入口引用链中，仍可能有手动用途，因此保留内容。

已删除根 `__pycache__/` 的4份可再生成字节码，合计235924字节。该目录后续可能由Python重新生成，属于正常缓存。实际任务的`.round-runtime/`、正文读取缓存、存档、语音配置、图片/语音资源，以及原机制管理的`.backup/`、`.operit/backups/`均保留。

默认源码检索通过 `开发者功能/.ignore` 跳过`归档/`和`修订日志/`；查历史时显式打开文件或使用`rg --no-ignore`。不支持`.ignore`的文件工具需自行限定搜索目录。`开发者功能/归档/项目清理/`已从自动同步排除，当前源文件和本清单仍保留同步；需要在其他设备恢复历史父版时，应读取原设备归档。

完整逐文件映射见 [文件迁移清单_25.json](文件迁移清单_25.json)。归档路径规则是“历史修改备份/ + 原相对路径”；不确定资料对应“用途待确认/ + 原相对路径”。旧安装清单、plan/logs和验收证据保持原位与历史原文，其中回滚命令仍引用搬迁前的备份位置。执行旧版本回滚前，必须先恢复相应父版原位，再按对应清单恢复源码；插件源码回滚后还需重建或还原安装包并同ID导入。

本轮验证使用VFS目录清单：全工作区与归档区的备份搜索均返回140份；各归档子目录中的文件名、大小与迁移前逐项对应。正式源码、知识库和当前桥接4文件仍可达，大小与本轮改前目录清单一致；根目录没有新增文件，临时目录为空。VFS移动更新了归档文件mtime，未声称保持原mtime。终端持续返回`Host service capacity exhausted: android-pty-reader`，因此本轮没有重新计算SHA-256、运行Python/Node或进行业务回归/实际回滚演练。目录核对不等同于字节级哈希或真实生成验收。

如需撤销本次归档，先停止任何并行文件维护，在项目根目录用系统Python执行下列单条命令。命令先检查全部来源、路径与冲突，再逆向移动140份父版和4份待定资料；任一原路径已有新文件即停止，不覆盖。另恢复本轮2份文档/配置父版并移除内容匹配的新增`.ignore`；保留清理交接证据，缓存由Python再生。**此命令已按清单编写，因终端不可用未执行验证。**

```bash
PYTHONDONTWRITEBYTECODE=1 python3 - <<'PY'
from pathlib import Path
import json, os, shutil, uuid
root = Path.cwd().resolve()
assert (root / 'AGENTS.md').is_file() and (root / '语音运行.py').is_file(), '请进入实际项目根目录'
m = json.loads((root / '开发者功能/修订日志/2026.11/回合执行基础/src/文件迁移清单_25.json').read_text(encoding='utf-8'))
def local(rel):
    p = root / rel
    assert p.resolve().is_relative_to(root) and not p.is_symlink(), rel
    return p
moves = []
for parent, files in m['backups_by_directory'].items():
    for name, size in files:
        rel = (Path(parent) / name).as_posix()
        moves.append((local(m['history_destination_prefix'] + rel), local(rel), size))
for rel, size, reason in m['uncertain_files']:
    moves.append((local(m['uncertain_destination_prefix'] + rel), local(rel), size))
parents = [(local(backup), local(rel), size) for rel, size, backup in m['maintenance_backups']]
ignore = local('开发者功能/.ignore')
ignore_text = '# 历史资料保留原位；常规源码检索跳过，查历史时显式指定路径或使用 --no-ignore。\n/归档/\n/修订日志/'
assert not ignore.exists() or ignore.read_text(encoding='utf-8').strip() == ignore_text.strip(), '.ignore已变化'
for source, target, size in moves:
    assert source.is_file() and source.stat().st_size == size, str(source)
    assert not target.exists(), '原路径已有文件: ' + str(target)
for source, target, size in parents:
    assert source.is_file() and source.stat().st_size == size, str(source)
# 文档与同步配置若在清理后又有更新，应先合并再恢复，勿直接覆盖。
sync = json.loads(local('.operit/sync.json').read_text(encoding='utf-8'))
old_sync = json.loads(parents[0][0].read_text(encoding='utf-8'))
expected_sync = dict(old_sync)
expected_sync['exclude'] = old_sync['exclude'] + ['开发者功能/归档/项目清理/']
assert sync == expected_sync, '同步配置已变化，请先合并'
manual = local('开发者功能/开发者说明书/开发者说明书.md')
assert manual.stat().st_size == m['maintenance_after_bytes']['开发者功能/开发者说明书/开发者说明书.md'], '说明书已变化，请先合并'
for source, target, size in moves:
    target.parent.mkdir(parents=True, exist_ok=True)
    shutil.move(str(source), str(target))
for source, target, size in parents:
    temp = target.with_name(target.name + '.round-tmp-' + uuid.uuid4().hex)
    try:
        with temp.open('xb') as stream:
            stream.write(source.read_bytes())
            stream.flush()
            os.fsync(stream.fileno())
        os.replace(temp, target)
    finally:
        temp.unlink(missing_ok=True)
ignore.unlink(missing_ok=True)
print('恢复文件位置完成；本条命令未回滚应用代码，旧版本回滚须再按原安装清单执行。')
PY
```

恢复到旧路径会重新出现历史备份，仅在明确回滚时操作。逐文件移动不是跨文件原子事务；操作中断时依据清单仅恢复尚未移动的条目，已存在的原路径先核对。正常继续开发时直接维护说明书列出的当前文件。
