# 故事页面与 Operit 2 使用说明

已完成页面提交、任务状态、结果提交与阅读恢复。原有手动 Python 注入入口保留。

## 启动与使用

1. 在 Pydroid3 运行项目根的 `语音运行.py`，访问 `http://127.0.0.1:5000`。
2. 打开Operit并保持小窗可见，在故事页行动面板点「启动桥接」。若首次使用或未连接，复制面板中的 `/storybridge start`，在Operit直接发送；固定指令由插件执行，不调用聊天模型。也可发送完整短句「启动故事桥接」，插件会直接处理。不要在“故事生成 · 项目工作区”专用聊天手动续写。模型使用Operit的`CHAT`功能绑定，页面在提交前显示实际模型。
3. 回故事页点击选项，或点右上方「行动」输入自定义行动，按「提交行动」。页面自动显示等待、生成、校验提交状态，通过后载入新回合。

首次启动后，桥接暂停时仍检查页面控制；后续可在页面启动/暂停，无需让AI理解启动句子。连接检查、桥接状态与行动进度分别显示。网页无法唤醒未运行的Operit，需先打开并保持小窗可见；Pydroid3服务也须持续运行。本机后台冻结已实测，前台可见小窗是已验证的运行方式。

桥接包已在当前 Operit 2 `2.0.0-preview.37` 导入并启用，交付时监听关闭。在新设备上从 `开发者功能/Operit故事桥接/故事桥接.toolpkg` 导入，再启用 `story_bridge`。不要按旧版 SandboxPackage 安装流程处理。

查看状态用 `/storybridge status` 或 `story_bridge:status`；暂停用 `/storybridge stop` 或页面「暂停桥接」。停止只阻止领取新任务，已经领取的任务完成一次。需要更换功能模型时先停止并等任务结束，再用 `story_bridge:configure` 传入 `functionType`，不修改 Operit 原来的模型绑定。

## 失败与恢复

- 网络结果不确定时，页面保存原始请求标识，点击「重试原行动」重传同一请求。
- 生成失败或租约过期时，保留原行动，点击重试会重新生成；迟到的旧结果失效。
- 回合 JSON 未通过执行器校验时不提交存档，页面显示拒绝原因。重试会再次使用模型，有调用成本。
- 基于旧场景的行动不自动改写版本；先检查最新场景，再重新提交。
- 模型结果在 Operit 插件配置和项目 `.round-runtime/story/` 中保存后再提交。传输失败复用已保存的结果；服务重启可恢复待提交结果。
- 浏览器刷新后，按快照版本恢复已读节点，语音暂停；需要时重新打开声音。更换浏览器或清除站点存储会丢失本地阅读位置，服务端任务仍保留。
- 不要在正在生成或提交时运行清档工具或手动覆盖存档。新档清理器已有互斥、事务恢复与跨档标识，应先停止本地服务和桥接再运行；不要手动删除data.json代替完整清理。

任务文件和上下文位于 `.round-runtime/story/`，已被现有同步规则排除；不要随意删除待恢复事务。任务记录目前不自动清理，长期使用会增长。

## 数据与设定边界

页面通过 `/api/story/snapshot` 一次读取正文、记忆和道具快照。行动携带该快照的版本；最终写入统一调用 `RoundStore.submit`。模型输出只作为 JSON 解析，禁止执行模型返回的代码。

每个任务独立读取全局记忆、注入指南、法典、提示词、检索索引、四个权威知识库和当前快照，附带来源指纹，不依赖当前开发聊天或世界书隐式挂载。内容仍由原始文件维护。按任务key提取所需原文并核验读取回执，相关原始文件仍为唯一维护源。硬校验约束格式、版本和数值写入，不保证设定语义绝对正确。

本地接口只接受回环 Host，同源页面写请求需要专用头，桥接回调需要本地生成的令牌；未开放外网接口。`语音运行.py` 继续绑定 `127.0.0.1`。

## 回滚

先停止故事服务和桥接，再执行以下一条命令（在项目根运行）：

```bash
python3 -B -c 'import json,pathlib,shutil; p=pathlib.Path("开发者功能/修订日志/2026.11/回合执行基础/src/安装清单_2.json"); m=json.loads(p.read_text()); [(shutil.copyfile(x["backup"],x["target"]) if x["backup"] else pathlib.Path(x["target"]).unlink(missing_ok=True)) for x in m["files"]]'
```

该命令仅恢复代码，保留 `.round-runtime/`、存档和语音配置。Operit 桥接包是本次新增对象，可在插件管理中禁用或删除 `local.story.operit_bridge`。逐文件原件/备份指纹见 `src/安装清单_2.json`。
