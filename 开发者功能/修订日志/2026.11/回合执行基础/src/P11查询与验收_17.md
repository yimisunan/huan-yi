当前：深渊天平引擎 / P11已安装并通过定向验收 / 收尾交接。

关系、继承知情资格与具体称谓候选集中到 `txt文件/关系称谓库.json`；旧角色/世界观条目改为查询引用，保留人物动机、语气风格与揭秘纪律。查询只提供候选，不替换或强迫台词，不推进剧情。

- 唯一源：12条公开关系 + 1条私有继承事实；血缘/社会/法律层分开。每一对关系只存一个方向，查询时翻转角色位置。沈知韫是K01唯一知情者；人物信念独立标为belief_not_fact。亡父为已故，不能作为当前说话者，公开父系关系在身份查询中保留。
- 新入口：`relationship_query.py`；`RelationshipRegistry(root).query(speaker, listeners, occasion)` 和 `.knowledge(perspective)`，只读。场合formal/relaxed/business，明确多人自称取交集；不明确对象时仅返回中性自称及公开身份事实。查询不接受额外知情或解锁参数。省略主语是候选之一。
- 派生视图：`txt文件/关系称谓查询.jsonl`，1行元数据 + 36行方向/未明确查询 + 5行知情查询。每方向含三场合，来源含源文件SHA与JSON Pointer。全部是程序生成物，不能手改；不作为另一份手写事实源。
- 桥接：只给合同元数据，不附全表；保留原8种文件只读工具、必读顺序与目录浏览。grep定位后读取第1行及所需行；服务记录实际方向key与covered_lines，不把部分行冒充全表。视图每次与唯一源及查询程序重生成结果逐字核对，陈旧或截断拒绝。一般资料提取与精简留给P12。

## 只读使用

```bash
python3 relationship_query.py query --speaker 苏婉青 --listener 沈知韫 --occasion formal
python3 relationship_query.py query --speaker 苏婉青 --listener 沈知韫 --listener 徐志北 --occasion relaxed
python3 relationship_query.py knowledge --perspective 徐志北
python3 relationship_query.py check
```

维护时先改唯一原库，再由 `python3 relationship_query.py render` 输出候选视图，验证后以备份/原子替换方式更新视图。不要在正文生成会话运行命令。档案指针和索引要求按需读取，平台已导入的世界书需另行导入新导出；本项未更改平台世界书配置。
