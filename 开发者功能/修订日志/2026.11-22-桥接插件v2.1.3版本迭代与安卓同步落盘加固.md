# 2026.11-22 · 桥接插件 v2.1.3 版本迭代、网页自动升级提醒与安卓同步落盘加固

> 日期：2026-11-22
> 范围：Operit 2 桥接插件版本体系（`scene_chat_dev/`）、后端 `_bridge_view()`、剧场前端 `story_client.js`、`一键同步GitHub.py` 与 `AI故事生成犯错未解决项/` 清理

---

## 1. 变更背景

1. 近期多次改动桥接源码并重打包时仍沿用 `2.1.2` 版本号与原文件名，玩家在手机端与网页端均无法直观判断本地是否已有新版插件包待覆盖导入。
2. 安卓 11+ `/storage/emulated/0/...`（MediaProvider FUSE）环境下，`一键同步GitHub.py` 此前通过 `.开头` 隐藏临时文件原地 `os.replace` 覆盖同名 `.toolpkg` 时，系统文件管理器与 Operit SAF 选择器的 `date_modified` 缓存可能停留在旧日期，且脚本未打印磁盘实测的插件版本号/写入时间/SHA-1，造成「同步日志显示更新、本地文件看起来仍是昨天」的困扰。

---

## 2. 核心改动

### 2.1 Operit 2 桥接插件版本迭代（`2.1.2` → `2.1.3`）与构建清理
- 同步递增插件版本号至 **`2.1.3`**：[`scene_chat_dev/local.story.operit_bridge/manifest.json`](../../scene_chat_dev/local.story.operit_bridge/manifest.json)、[`main.js`](../../scene_chat_dev/local.story.operit_bridge/main.js)（`PLUGIN_VERSION`）、[`ui/settings.ui.js`](../../scene_chat_dev/local.story.operit_bridge/ui/settings.ui.js)、[`README.md`](../../scene_chat_dev/local.story.operit_bridge/README.md)、[`游玩指南.md`](../../游玩指南.md) 与根目录 [`.gitignore`](../../.gitignore) 白名单。
- [`scene_chat_dev/build.py`](../../scene_chat_dev/build.py) 在新包 ZIP 与 `manifest.json` 校验通过后自动清理 `scene_chat_dev/artifacts/` 中的旧版 `故事桥接-continuous-*.toolpkg`，保证仓库始终仅保留单一最新包（`故事桥接-continuous-2.1.3.toolpkg`）。
- [`scene_chat_dev/tests/bridge_settings_ui.js`](../../scene_chat_dev/tests/bridge_settings_ui.js) 改为动态读取 `manifest.json` 校验 `snap.version`，避免后续迭代硬编码脱节。

### 2.2 网页端自动检测旧版插件并提醒导入
- [`story_service.py`](../../story_service.py) 新增 `StoryService._expected_plugin_version()`（按 `manifest.json` `mtime_ns`/`size` 轻量缓存）并在 `_bridge_view()` 透出 `expected_plugin_version`。
- [`story_client.js`](../../story_client.js) 增加语义版本比对 `isOlderSemver(cur, target)`：当已连接 Operit 插件 `plugin_version < expected_plugin_version` 时，在 `#bridgeInfo` 直接展示 `· 有新版 v2.1.3 待在 Operit 导入`，并在 `#storySessionStatus` 附带对应 `.toolpkg` 路径指引。

### 2.3 `一键同步GitHub.py` 安卓 FUSE 落盘加固与二次验真
- `atomic_write_bytes()` / `atomic_copy_file()` 改用**非点号临时文件名**（`{dest.name}.sync-tmp-{pid}`，仍受 `LOCAL_ONLY_MARKERS` 忽略），写入后强制 `flush()` + `os.fsync()`，并在 `os.replace()` 之后显式调用 `_touch_mtime()`（`os.utime(dest, None)`）刷新可见路径修改时间。
- `apply_sync_plan()` 对每个新增/更新文件执行**落盘后 Git Blob SHA-1 二次校验**，与远端指纹不一致立即抛错阻断；同步完成摘要直接打印 `.toolpkg` 磁盘实测的**内部版本号、字节大小、本地写入时间与 SHA-1**，并扫描告警 `scene_chat_dev/artifacts/` 残留旧包。

### 2.4 清空已解决历史问题证据目录
- 清空 `AI故事生成犯错未解决项/` 下已全部修复收口的 `101`、`data.json`、`save_state.json`、`近期演播.json`（保留目录说明标记文件）。
