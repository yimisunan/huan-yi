# 2026-11-26 主角与人物面板全属性沉浸式释义手记

> 范围：剧场前端交互与样式（`story_client.js`、`story_client.css`）及开发者架构说明（`开发者功能/开发者说明/05_前端剧场与语音引擎架构.md`、`README.md`）。

## 1. 需求背景

玩家点进「主角」与「人物名册」查看主角魅力、商业嗅觉、体能/欲耐及女主好感、羞耻、欲望、堕落、状态标签与监视态势时，原先缺乏就地展开的沉浸式简要说明，难以直观了解各项数值的实际作用、门槛收益及增减条件。

## 2. 核心改动

- **统一沉浸式属性释义库（`story_client.js` → `STAT_GUIDE` / `buildStatGuidePanel()`）**：
  - 严格对齐 `injection_core.py` 与 `story_progression.py` 的真实确定性规则，杜绝暴露底层事件代码，面向玩家提供精炼的「**作用 / 增长 / 减少**」三栏结构化说明与顶部实时状态行（自动计算当下阶梯、下一门槛差值、羞耻动态天花板 `100 − ⌊堕落×0.6⌋` / 孕期 `≤ 35` 锁顶、体液锁定保底、控欲边缘 `+10%` 高潮倍率、高羞耻完好防线与苏婉青 85 门槛提示、当前商城魅力折扣及可立即升级的被动对象）。
  - 交互采用无弹窗原位展开（`inspectedHostStat` / `inspectedCharStat`），保留弹窗滚动位置，再次点击或点击 `收起 ×` 即折叠。
- **主角页全覆盖（`renderHostTab`，8 项）**：
  - 体能与欲耐区：`当前体力`、`亲密耐力（精力）`、`宿主欲望`、`道具恢复额度` 全部改为可点击行（附 `ⓘ` 轻提示与选中高亮）。
  - 核心四维卡：`积分`、`经验值`、`魅力`、`商业嗅觉` 全部支持点按查看释义；`积分` 与 `经验值` 展开后在手记底部保留「前往系统商城 →」/「前往名册解锁被动 →」一键跳转。
- **人物名册页全覆盖（`renderRosterTab`，13 项 + 身体开发简明手记）**：
  - 五维属性条：`好感`、`羞耻`、`体力`、`欲望`、`堕落` 均支持点按展开释义卡。
  - 次级状态标签：`高潮`、`内射`、`怀孕`、`孕育状态`、`被动`、`生理周期`、`欲求积压` 均改为可点按胶囊。
  - 身体开发折叠卡：补充五区开发阶梯（`Lv.0–3`）、高潮推进加成、招牌部位 `1.35×` 成长及首破 `Lv.2/3` 奖 `+1` 魅力的简明手记。
  - 徐承邺监视态势卡：标题改为可点按触发 `警惕与发现` 释义面板（说明 50/70 回返概率、异常/眼线/目击增益、每小时 `-2` 衰减与目击锁 `>=50` 不衰减）。
- **黑金 / 暖纸双主题与移动端防溢出样式（`story_client.css`）**：
  - 新增 `.stat-guide-panel`、`.stat-info-dot`、`.is-inspectable` / `.is-inspected` 及 `ivory` 浅色主题对比度适配，全部容器采用 `minmax(0, 1fr)` 与 `min-width: 0` 保证窄屏零横向溢出。
