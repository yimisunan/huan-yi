# 2026-11-25 Operit 2 工作区 ID 协议适配（v2.1.9）与连接弹窗移动端防溢出

> 范围：Operit 2 桥接插件（`scene_chat_dev/local.story.operit_bridge/` `v2.1.8 → v2.1.9`、`scene_chat_dev/artifacts/故事桥接-continuous-2.1.9.toolpkg`、`scene_chat_dev/tests/bridge_settings_ui.js`）与剧场移动端样式（`story_client.css`）。

## 1. 问题背景

1. **Operit 2 框架工作区模型升级导致 `workspace does not exist`**：Operit 2 上游（`core/crates/command/core/src/commands/workspace.rs`）将工作区重构为一等持久化实体，`workspace bind <chat-id> <workspace-id>` 不再接受文件系统或 VFS 路径，只接受已创建的工作区 UUID。桥接插件旧版将用户填写的目录路径（如 `/storage/emulated/0/互动对话项目/Gemini网页版`）原样传入 `workspace bind`，且校验强硬要求以 `/` 开头，导致绑定必然报错。
2. **「连接与桥接」折叠面板在手机端横向超出屏幕**：`story_client.css` 中 `<details class="bridge-group-card bridge-fold">` 继承了 `.bridge-group-card` 的 `display: grid`，且 `.bridge-fold-body` / `.bridge-subgrid` / `.picker-block` 未声明 `grid-template-columns: minmax(0, 1fr)`，`select` 也未限制 `max-width: 100%`，导致较长下拉选项把整个卡片向右撑出视口。

## 2. 核心改动

### 2.1 Operit 2 桥接插件适配（`v2.1.9`）
- **智能工作区解析与绑定（`main.js`）**：
  - 新增 `bindWorkspaceToChat()` 与 `fetchWorkspacesList()`：优先直接执行 `workspace bind <chatId> <target>`（兼容已填 UUID 或旧版 Operit 2）；若返回不存在错误，自动调用 `workspace list --json` 与 `workspace resolve-path --native` 检索已有工作区，按 ID、规范化路径（兼容 `/storage/emulated/0`、`/sdcard`、`<nodeId>:` 节点前缀）及安卓 SAF 工作区/目录名（如 `Gemini网页版`）自动匹配到对应 `workspaceId` 并完成绑定。
  - 若目标路径尚未在 Operit 2 中登记，自动尝试 `workspace create <name> --native|--vfs <path> --json` 创建并绑定；若仍失败则附带当前已有工作区列表的中文排查指引。
  - 新增 `auditWorkspaceValue()`，在配置为工作区 UUID 时仍向后端工具审计透传已解析的真实目录路径，保证 `story_service._audit_path` 与 `interaction_runtime` 路径校验兼容。
  - 放宽 `update_settings` 与 `configure` 的 `workspacePath` 校验以同时接受工作区 UUID 与目录路径，修改时清空 `boundChatCache` / `resolvedWorkspacePathCache` 及陈旧工作区报错。
- **原生设置页一键工作区选择器（`ui/settings.ui.js`）**：
  - `fetchModelCatalog()` 同步拉取 `availableWorkspaces` 并在设置页快照中透出。
  - 「高级连接配置」新增「快速选择 Operit 已有工作区」胶囊行，点击即可直接绑定对应工作区 ID，折叠态自动显示工作区名称与短 ID。
- **构建产物**：`manifest.json` 与 `main.js` 同步升级 `2.1.9`，经 `scene_chat_dev/build.py` 打包生成 `scene_chat_dev/artifacts/故事桥接-continuous-2.1.9.toolpkg` 并清理旧 `2.1.8` 包。

### 2.2 移动端连接与折叠面板防横向溢出（`story_client.css`）
- `.bridge-fold` 显式设为 `display: block !important; min-width: 0; max-width: calc(100% - 28px);`。
- `.bridge-group-card`、`.bridge-fold-body`、`.bridge-subgrid`、`.picker-block`、`.action-card-form`、`.hub-fold-body` 统一补充 `grid-template-columns: minmax(0, 1fr); min-width: 0;` 及子项 `min-width: 0;`。
- `select` 补充 `width: 100%; max-width: 100%; overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`，`.action-row > select` 设为 `flex: 1 1 0%; width: 0; min-width: 0;`，`.connection-scroll` 补充 `overflow-x: hidden;`。
