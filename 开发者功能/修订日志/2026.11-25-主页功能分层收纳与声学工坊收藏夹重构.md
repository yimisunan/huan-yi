# 2026-11-25 主页功能分层收纳与声学工坊收藏夹重构

> 范围：正式剧场功能弹窗（`main_template.html`、`story_client.js`、`story_client.css`）、声学工坊（`voice_manager.html`）与语音收藏夹接口（`语音运行.py`）。

## 1. 问题背景

1. 主页档案中心（`#worldDialog` 各页签）、出行与赠礼（`#actionDialog`）及连接与桥接（`#connectionDialog`）均采用整页平铺布局，移动端查找特定开关、道具分类或商城品类需反复长滚屏。
2. 声学工坊（`/admin`，`voice_manager.html`）顶部密钥/说明区与单角色全部参数面板同时展开，首屏负担过重；全局音色收藏库（`voice_repo`）仅提供下拉选择且缺乏一键收藏、直接试听、改名备注与删除入口。

## 2. 核心改动

### 2.1 主页功能界面分层与折叠收纳
- **系统设定（`system`）**：拆分为 `剧场显示` / `语音与密钥` / `背景音景` / `连接维护` 4 个子页签；次要视觉开关收进「细节视觉与触感」折叠块，已配置的 Fish API 密钥默认收折为单行状态条。
- **委托与行囊（`bag`）**：拆分为 `随身` / `珍藏` / `委托` / `已部署` / `已赠予` 5 项带数量角标的子页签（存在待领奖励时自动标金点并优先定位「委托」，贴身私密珍藏独立归入「珍藏」页签）。
- **系统商城（`shop`）**：顶部新增货架分类筛选胶囊，「AI 定制询货」默认折叠（询货进行中或有回复时自动展开）。
- **主角档案（`host`）与人物羁绊（`roster`）**：「魅力阶梯与显露癖好」、「商业嗅觉与一次性情报」、女主「身体开发 · 部位敏感度」与「定向被动升级」均改为带实时摘要的折叠卡（可入库/可升级/已预备杠杆时自动展开），存档概览压为单行摘要条。
- **出行与赠礼（`#actionDialog`）与桥接面板（`#connectionDialog`）**：`#actionDialog` 改为 `前往他处` / `赠予人物` 双页签；`#connectionDialog` 3 块大表单改为带状态徽标的折叠手风琴。

### 2.2 声学工坊工作台与可视化收藏夹
- **后端新增 `PATCH /api/voice_repo`（`语音运行.py`）**：支持直接更新收藏音色的 `name` 与 `note`（统一受 `X-Voice-Client: 1` CSRF 守卫保护）。
- **顶部工具条收敛（`voice_manager.html`）**：原 `.top-meta-grid` 收敛为单行 `.studio-toolbar`（全局 3 档切换 + `密钥与额度` 折叠抽屉 + `★ 收藏夹 (N)` 快捷入口），仅未配置密钥时自动展开抽屉。
- **3 页签角色工作台**：
  - `音色与试听`：角色头卡新增 `☆ 收藏当前` / `★ 已收藏` 一键星标；搜索公开音色升级为带 **`▶ 试听` / `✓ 选用` / `☆ 收藏`** 三键的卡片列表；候选芯片新增一键星标收藏；导演试听台的临时情绪与快捷标签收进折叠区。
  - `★ 收藏夹 (N)`：可视化收藏卡片列表，支持实时关键词筛选、一键收藏当前角色、手动粘贴 ID 折叠表单，每条收藏直达 **`▶ 试听`**（沿用自定义试听草稿不覆盖配置）、**`✓ 设为当前角色`**、**`✎ 改名/备注`**（`PATCH /api/voice_repo`）与 **`🗑 删除`**（`DELETE /api/voice_repo`）。
  - `参数微调`：保留预设条与最常用的「韵律与动态响度」展开，其余 3 组进阶参数收进带当前数值摘要的 `.param-fold` 折叠区。
