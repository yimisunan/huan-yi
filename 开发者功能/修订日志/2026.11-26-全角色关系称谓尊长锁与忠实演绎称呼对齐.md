# 2026-11-26 全角色关系称谓尊长锁与忠实演绎称呼对齐

> 范围：关系称谓解析与原库（`relationship_query.py`、`txt文件/关系称谓库.json`、`txt文件/关系称谓查询.jsonl`）、编译器与规则源（`story_compiler.py`、`txt文件/知识库/角色类.json`、`txt文件/场景交流规范.md`、`Operit世界书导出/operit_worldbook_深渊天平.json`）及回归测试（`scene_chat_dev/tests/test_story_compiler.py`）。

## 1. 问题背景

1. **全角色常规称谓与自称存在名字简称提前泄露**：`relationship_query.py` 原仅在 `ELDER_ROLES`（父母/婆婆）上屏蔽自动前置 `short` 名字简称，未覆盖同辈尊长（`elder_sister`、`elder_brother`、`sister_in_law`）与 `次要NPC`，且未收紧非晚辈对长辈的自称简称，导致编译进 Zone 1 的称谓表中出现：
   - `徐志北 -> 徐念薇 / 苏婉青 / 徐承邺`、`徐念薇 -> 苏婉青 / 徐承邺` 在正式/放松/商务场合首位全为直呼名字（`"念薇"`、`"婉青"`、`"承邺"`）；
   - `徐念薇 / 苏婉青 / 徐承邺` 对弟妹/小叔及 `沈知韫 -> 次要NPC` 常规自称首项出现本人名字简称；
   - `次要NPC -> 沈知韫 / 苏婉青 / 徐念薇 / 徐承邺 / 徐志北` 首位出现直呼闺名/小名。
2. **忠实演绎 `[D:徐志北]` 与 `intimate` 称谓缺少精细边界**：玩家输入「（眼神示意姐姐去拿药膏）母亲，您有没有受伤」时，模型将「母亲」改叫「妈」、将无声眼神示意扩写成开口直呼「念薇」，且多人同场时未限定 `i` 私密称谓仅对独处/失守的特定对象单独生效。

## 2. 核心改动

- **关系称谓解析器收口（`relationship_query.py`）**：
  - 新增 `SENIOR_ADDRESS_ROLES = ELDER_ROLES | {'elder_brother', 'elder_sister', 'sister_in_law'}`。
  - `query()` 与未知听众分支收紧 `include_short`：称呼尊长及 `次要NPC` 称呼徐家成员均不自动前置 `short`；常规自称仅在晚辈面向长辈（`listener_is_elder`）时附带 `short`，其余统一走「我」+ 亲属自称（私密闺名仅由 `intimate` 显式配置提供）；长辈叫晚辈、兄姐/嫂叫弟妹/小叔与夫妻互称保持自然简称不变。
- **关系称谓库与派生视图（`txt文件/关系称谓库.json`、`txt文件/关系称谓查询.jsonl`）**：
  - `title_rules` 由 2 条扩充至 **5 条**，补齐 `次要NPC -> 徐念薇 / 徐承邺 / 徐志北` 的正规外部称谓（`徐小姐/二小姐`、`大少爷/徐总/徐先生`、`二少爷/徐少爷/徐先生`）。
  - 精修 `selection.rule`，并经 `relationship_query.py render` 重新生成 `关系称谓查询.jsonl`（42 行指纹校验通过）。
- **编译器、角色边界与规范对齐（`story_compiler.py`、`角色类.json`、`场景交流规范.md`、`Operit世界书导出/`）**：
  - `compile_relationships()` 的 `rule` 明确常规/公开场对母亲/姐姐/嫂子/大哥禁直呼名字，`i` 私密称谓仅对独处或失守的对应特定对象单独生效、禁扩散至同场旁观亲属。
  - `build_zone0_global()`（`faithful`）、`char.徐志北` 与 `场景交流规范.md` 同步补充：`[D:徐志北]` 称呼人物须严格沿用玩家本轮原输入称谓，括号内无声/眼神示意不擅自改写为喊话；同步重导 24 条 Operit 世界书。
- **回归测试（`scene_chat_dev/tests/test_story_compiler.py`）**：新增全角色 30 组称谓/自称及 `次要NPC` 边界断言。
