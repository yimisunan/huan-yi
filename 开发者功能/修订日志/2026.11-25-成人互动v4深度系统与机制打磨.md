## 1. 背景与目标

针对 `开发者功能/调研目标.md` 提出的 5 项成人互动体验短板（主角自身情欲与射精控欲缺位、亲密场中段日常体力耗尽强迫 `resting`、女主身体分部位开发/特色偏爱缺失、魅力属性长期闲置、私密贴身收藏与癖好闭环缺失），在不修改 `txt文件/事件注册表.json` 现有 85 项注册表结构与不突破 `Zone 0/1` / `Stage 2` 提示词预算的前提下，落地 v4 确定性引擎、前端剧场 UI 与持久化闭环，并完成记忆持久化、魅力收支平衡及运维工具兼容性三项专项打磨。

## 2. 核心变更

### 2.1 主角情欲与控欲（`intimate.host_phys`）
- `save_store.py` 在 `save_state.intimate` 新增 `host_phys`（`desire: 0–100`、`vigor: 0–100`、`release_count`、`edging_streak`、`fetishes[]`：`足踝黑丝控` / `丰盈胸乳控` / `冷白玉手控` / `唇舌掌控欲` / `贴身私藏癖`）。
- **控欲边缘（`desire >= 85`）**：严格遵守卷零轨 A 宿主主权（永不代主角自动射精），进入控欲状态为女主高潮增速附加 `+0.10` 倍率。
- **释放与同步绝顶**：触发 `SHAME_05`（`外射_体表面部`）/ `SHAME_06` / `SHAME_07` 或 Stage 2 `scene_state.host_release=true` 时判定释放；若同回合女主达绝顶清算，触发 `synced_climax`（单场亲密会话限领一次 `+1` 魅力，通过 `intimate.session_charm_gained` 防刷）。
- **自然冷却**：跨地点 `-15`、平静 A 档 `-6`、非亲密跨时（`elapsed_hours >= 2`）每小时 `-5`（单次封顶 `-30`）；整夜睡眠高欲（`>=70`）留底 `25`，其余归 `0`。

### 2.2 亲密体能双池与保底护盾（`vigor` + `intimate_stamina_floor`）
- `txt文件/互动运行配置.json` 将亲密续演三档体力由 `5/7/10` 降为 **`1/2/3`**，新增 `intimate_stamina_floor: 10`、`vigor_maximum: 100`、`vigor_min_floor_guard: 15` 与 `vigor_costs: {"A":2,"B":4,"C":7,"release":12}`。
- `story_progression.py` 新增 `stamina_guard_info()` 与 `apply_stamina_floor()`：只要亲密场进行中且精力池 `vigor >= 15`，日常体力绝不跌破 `10`（当前 `<= 10` 时预扣为 `0`），彻底消除“亲热到一半体力归零被迫 `resting`”的断戏问题。
- 恢复道具同步补 `+15/+25` 精力，肾上腺素事件同步补 `+25` 精力，整夜睡眠双池均恢复至 `100`；前端 `story_client.js` 全部 11 处硬编码 `afford(15)` 改为动态 `customReserveCost()`。

### 2.3 三女主五区身体开发与特色部位（`intimate.body_dev`）
- `save_state.intimate.body_dev` 为三女主追踪 5 个只增不退的敏感区 `oral / hand / chest / foot / core`（`0–100`，4 阶：`Lv.0 生涩防备 / Lv.1 敏感初开 / Lv.2 熟稔沉溺 / Lv.3 彻底开发`）。
- 专属特色部位锁定：`沈知韫 → foot`（玉足黑丝）、`苏婉青 → chest`（36D 胸乳锁骨）、`徐念薇 → hand`（冷白双手腕骨）。
- **双通道提取**：优先读取 Stage 2 `scene_state.body_acts`，缺省时由确定性文本兜底 `infer_body_acts_from_prose()` 补全；命中特色部位享 `×1.35` 成长（`+8/+16` vs `+6/+12`）、额外 `-1` 羞耻渗透与 `+3` 欲望；开发阶梯为高潮倍率附加 `+0.05 / +0.12 / +0.22`，首次跨入 `Lv.2` / `Lv.3` 奖 `+1` 魅力。

### 2.4 五阶魅力重构与收支平衡（`CHARM_TIERS`）
- 建立 5 阶魅力体系（默认 `70` 中性档）：`0–69 / 70–74 / 75–84（锋芒初显）/ 85–94（磁吸掌控）/ 95–100（深渊魅影）`：
  - `75`：正好感 `+1`、轻/中越界减伤 `25%`、`DS_06` 门槛降至 `60（+2 欲望）`、商城 `9 折`、释放精力 `-11`；
  - `85`：轻/中越界减伤 `40%`、C 档额外 `-1` 羞耻、高潮 `+8%`、商城 `85 折`、释放精力 `-9`；
  - `95`：正好感 `+2`、轻/中 `50%` & 深/重 `20%` 减伤、C 档额外 `-2` 羞耻、高潮 `+15%`、商城 `85 折`、释放精力 `-8`。
- **成长与折损平衡**：正向来源覆盖 `HOST_16`（同场限 1 次）、被动升级（`+1`）、部位首破 Lv.2/3（`+1`）与同步绝顶（单会话限 1 次）；负向折损（单回合封顶 `-2`，底线 `60`）覆盖 `VIGILANCE_01/02` 撞破（`-2`）、`SHAME_09/14` 羞耻反噬（`-1`）、精力/体力力竭 `collapse`（`-1`）及对高羞耻（`>=75`）低堕落（`<15`）女主冒进执行 `keepsake_action: confront`（`-1`）。

### 2.5 私密珍藏盒与互动操作（`intimate.keepsakes` + `keepsake_action`）
- 独立于商城/委托 `resolution.items` 防刷体系，存于 `save_state.intimate.keepsakes`（上限 24 件 `KS-XXX`：`kind ∈ {panties,stockings,bra,nightwear,accessory}`、`method ∈ {stolen,taken_intimate,gifted}` 且自动归一化 `kept_after` 别名、`condition ∈ {fresh_warm,stained_damp,faded}` 跨夜 `fresh_warm → faded`、`owner_aware`）。
- 通过 Stage 2 `scene_state.keepsake_adds` / `keepsake_updates` 登记，并在 `txt文件/互动运行配置.json` 注册第 8 项正式操作 `keepsake_action`，支持 `sniff_play`（独处嗅闻把玩 `+18` 欲望）、`confront`（当面亮出对峙置 `owner_aware=True`）、`use_intimate`（亲密助兴 `faded → stained_damp`）、`return_secret`（悄然归还并移除）。

### 2.6 打磨加固、持久化与运维兼容
- **双视角持久化**：`save_store.render_memory_txt()` 将非默认 `host_phys`、`body_dev` 与 `keepsakes` 渲染进 `【情欲与空间态势】`，`load_bundle()` 在 `.txt` 外部编辑漂移时严格保护 `intimate` JSON 真相不回退。
- **前端剧场呈现**：主角页新增精力/欲火/5 阶魅力权益/癖好卡；人物羁绊新增 5 区身体开发进度条与特色部位徽标；行囊新增「私密珍藏盒」独立分栏与快捷互动筹码；商城实时显示魅力折后价；顶部 `#sceneAtmospherePills` 补齐主角精力/欲火微标。
- **存档清理器与同步脚本**：`存档清理器.py` `_summarize_save_state()` 摘要增显 `魅力` 与 `私密珍藏` 件数，轻量化档槽与 `一键同步GitHub.py`（`SEED_ONLY_DIRS`）经验证与全部 v4 字段零冲突。
