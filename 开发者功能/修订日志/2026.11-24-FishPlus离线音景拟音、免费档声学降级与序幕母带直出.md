# 2026-11-24 · Fish Plus 离线音景拟音、免费档声学降级与序幕母带直出

## 一、变更背景

在主程序已完成三档语音分流与成人核心 v3 架构后，进一步落地 Fish Audio Plus 网页积分离线资产转化能力与默认免费档（`s2.1-pro-free`）的声学表现力修复：在不依赖额外实时 API 支出的前提下，支持本地永久氛围底噪、电影级交互与剧情拟音、角色原声干声试听、10 套开局序幕离线母带秒播，以及基于角色实时生理/情欲状态的动态韵律微调。

## 二、核心改动

1. **免费档声学智能降级与生理韵律调制（[`语音运行.py`](../../语音运行.py)）**：
   - 新增 `_degrade_drama3_for_s2()`，在 `s2.1-pro-free` / `s2.1-pro` 下将 `<whisper>/<soft>/<slow>/<fast>` 无损降级为 `[whispering]` / `[soft tone]` / `[slowly]` / `[speaking fast]`。
   - 升级 `_normalize_s2_chinese_aliases()`：扩充亲密气声/沙哑/发紧/发颤/羞耻短别名，并新增 `_S2_CN_KEYWORD_RULES` 自动从自由中文导演长句抽取英文控制词（避免 S2 漏读或忽略）。
   - `_prepare_tts_job()` 与 `_build_fish_payload()` 支持 `speed_scale`（`0.85–1.10`）与 `expressive_boost`（`0.0–0.12`），按实时高潮/欲望/体力态动态微调语速与表现力并隔离缓存键。
2. **本地永久音频资产服务与序幕离线母带秒播（[`语音运行.py`](../../语音运行.py)）**：
   - 启动入口 `_ensure_audio_dirs()` 自动建好 `txt文件/audio/{ambient,sfx,prologues,samples}/` 与防安卓媒体库扫描的 `.nomedia`。
   - `_serve_public_file()` 放行 `txt文件/audio/` 白名单音频后缀，新增 `scan_audio_assets()` 与 `GET /api/audio_assets` 零配置发现四类资产。
   - 新增 `_resolve_offline_master_audio()` 自动匹配 `存档开局随机盲盒.py` 10 套序幕原文；`/api/tts` 命中时直接返还 `X-Fish-Model: local-master`（`X-Audio-Source: offline-master`），无 API Key 亦可 0ms / \$0 离线秒播，并由 `prewarm_tts_items()` 自动跳过预热。
3. **前端双轨交叉淡入音景、Audio Ducking、拟音与原声试听（[`voice_client.js`](../../voice_client.js)、[`story_client.js`](../../story_client.js)、[`story_client.css`](../../story_client.css)）**：
   - `VoiceClient` 导出 `getAudioAssets()`，`buildPayload()` 与 `prefetchBatch()` 透传 `speed_scale` / `expressive_boost`。
   - `story_client.js` 新增双 `<audio>` 轨平滑交叉淡入淡出音景 `syncAmbientSoundscape()`（按昼夜/警惕/亲密/余韵自动换曲）、TTS 播报自动压低背景音 `duckAmbient()`（压至 28%）、交互与剧情事件拟音 `playSfx()` / `playContextSfxForMessage()`、系统设定「本地音景与离线母带」控制卡、人物羁绊页 `▶ 试听原声` 按钮 `playVoiceSample()` 与动态生理韵律计算 `computeProsodyMod()`。
4. **本地素材保护与使用教程（[`一键同步GitHub.py`](../../一键同步GitHub.py)、[`.gitignore`](../../.gitignore)、[`05_FishPlus网页积分素材制作教程.md`](../../语音引擎升级方案/05_FishPlus网页积分素材制作教程.md)）**：
   - 将 `txt文件/audio/` 加入 `LOCAL_ONLY_NESTED_DIRS` 与 `.gitignore`，确保增量同步与 `--prune` 绝不误删玩家本地音频素材。
