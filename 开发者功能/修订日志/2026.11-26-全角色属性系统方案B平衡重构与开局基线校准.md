## 1. 背景与核心问题

基于全仓代码审计与多维度数值推演，原属性体系存在 6 类结构性失衡与 9 处联动缺口：
1. **被动 Lv.3/4 经验断崖**：`20 / 50 / 200 / 800` 总计 `1070` 经验值远超正常游玩周期；且 `Lv.2` 即提前解除高羞耻完好防线，导致 `Lv.3/4` 定位重叠，多重减伤（Lv.2 + 杠杆 + 魅力 + Buff）叠加可把高烈度惩罚压成 `0`。
2. **商业嗅觉被三轨竞价吞没**：`HOST_09/10/11` 在三轨竞标败给高分侵蚀轨时连带丢失商业嗅觉，且 `60 → 100` 之间存在 40 点空窗，商业杠杆单次消耗珍贵一次性情报性价比偏低。
3. **高潮倍率后期无顶与部位开发过快**：五项正向加成线性叠加最高达 `1.97×` 且与受孕预估公式脱节；单回扫中多部位按 `+6/+12`（`×1.35` 达 `+16`）仅 5–6 轮即可满级并引发同回多次 `+1` 魅力。
4. **同回羞耻上限滞后与低体难回神**：堕落抬升后 `shame_cap` 需等下回合才夹紧；NPC 跌入断电后小憩仅 `+10` 且纯日常照料无缓气回体。
5. **开局面板扁平与商城门槛穿透**：沈知韫开局 `好感 95` 几近封顶（仅留 5 点空间），三女主羞耻全 `100` 缺乏性格区分，`SHOP-011~014` 依赖单轴好感可被开局高好感直接穿透。
6. **负反馈与深阶联动空白**：魅力 `<68`、耐力 `<15`、连续极限控场 `edging_streak >= 3`、内射 `>= 3` 次与确诊怀孕缺少对应机制反馈与叙事注入。

## 2. 方案 B 核心改动

### 2.1 P0 紧急失衡修复（6 项）
- **被动 EXP 曲线重塑与防线收口**（`txt文件/互动运行配置.json`、`story_progression.py`、`injection_core.py`）：
  - 定向被动升级开销调整为 **`Lv.1=20 / Lv.2=50 / Lv.3=110 / Lv.4=220`**（总计 `400` 经验）。
  - **Lv.3 疲劳诱导**新增体倦动摇联动：目标女主 `体力 < 60` 且活跃 C 降羞时额外 **`-1` 羞耻**。
  - **高羞耻完好防线修正**收紧为 `cur_passive < 4`（仅 **Lv.4 防线支配**可豁免）；多重越界好感减免（Lv.2 / 杠杆 / 魅力 / 官能 Buff / 撞破自渎）叠加上限封顶 **75%**，原始扣分 `> 0` 时保底 **`-1`**。
- **商业嗅觉独立结算 + 80+「深局棋手」+ 3 次杠杆护盾**（`injection_core.py`、`story_progression.py`、`save_store.py`、`txt文件/商业情报目录.json`）：
  - `process_host_system()` 保留三轨积分/经验择优，但 `商业嗅觉` 改为**独立累加结算**（单回上限 `+20`）。
  - 新增 `商业嗅觉 ≥ 80` **「深局棋手」**档：三轨胜出积分/经验额外 **`+15%`**，且徐承邺监视矩阵非目击类警惕增幅 **`-15%`**。
  - 商业杠杆升级为消耗 1 条情报展开 **3 次越界护盾**（持久化 `intel.leverage_charges` `0..3`），每次 C 烈度负向惩罚触发时减半越界掉好感并额外压制当轮至多 **`-10` 点非目击警惕**（非 C 烈度不浪费）。
- **高潮倍率 1.50× 软顶与受孕口径统一**（`injection_core.py`）：抽出统一 `_compute_orgasm_mult()`（钳制 `[0.45, 1.50]`），同时供给 `process_desire_stamina_system()` 与 `_estimate_turn_orgasm()` / `process_pregnancy_rng()`。
- **五区部位开发限速、2 区聚焦与单回魅力 `+1` 封顶**（`injection_core.py`、`story_progression.py`）：成长步长降为轻中 **`+4`** / 深度 **`+8`**（招牌 `×1.35` 为 `+5 / +11`），新增 `MAX_BODY_ACTS_PER_TURN = 2` 与 `_prioritize_body_zones()`（优先保留招牌敏感带）；`advance_intimate_state()` 透传 `charm_gained_this_turn` 强制单回净魅力涨幅 **`<= +1`**。
- **同回 `shame_cap` 实时夹紧**（`injection_core.py`、`story_progression.py`）：`apply_story_events()` 堕落结算与跨夜自渎 `+2` 堕落后均立刻按 `shame_cap` 夹紧羞耻。

### 2.2 P1 体验深化与开局校准（6 项）
- **魅力 `< 68` 气场受挫档**（`injection_core.py`）：`CHARM_TIERS` 拆分 `0~67（气场受挫：释放耐力消耗 14，魅力突破门槛升至 75）` 与 `68~74（清俊克制）`。
- **耐力透支与极限控场双联动**（`injection_core.py`、`story_compiler.py`）：`edging_streak >= 3` 时高潮倍率 `+0.15` 并每回额外扣耐力 `-2`；`vigor < 15` 时高潮倍率 `-0.15`；编译器同步向叙事端注入「极限控场」「动作略沉」「深局棋手」「商业牵制底气」「孕期易倦」定性简报，并清除旧版徐承邺堕落残留文本。
- **NPC 体力回复与孕期疲劳**（`txt文件/事件注册表.json`、`injection_core.py`、`story_progression.py`）：`DS_12（恢复_小憩）` 由 `+10` 调至 **`+15`**；纯 A 级平和照料回合若目标 `体力 <= 25` 且无消耗标签自动缓气回体 **`+5`**（封顶 `30`）；确诊怀孕跨夜体力恢复封顶 **`88`**。
- **开局基线与盲盒委托对齐**（`save_store.py`、`存档开局随机盲盒.py`）：沈知韫开局好感调整为 **`82`**（留 18 点成长与委托空间，`zhiyun_rain_balcony` 首环委托目标由 `97` 调为 `85`）；三女主初始羞耻按人设分化为 **沈知韫 `100` / 徐念薇 `96` / 苏婉青 `92`**。

- **运行时预览同步**（`round_runtime.py`、`interaction_runtime.py`）：生命周期预演透传 `host_charm` 与 `privacy`，体液锁定视图透传 `creampie_count`。
