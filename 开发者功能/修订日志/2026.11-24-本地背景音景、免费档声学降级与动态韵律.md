# 2026-11-24 · 本地背景音景、免费档声学降级与动态韵律

## 一、变更背景

在主程序已完成三档语音分流与成人核心 v3 架构后，进一步补充不依赖 Fish 手工抽卡素材的轻量语音与氛围增强：保留 5 首本地循环背景音景（直接放入免费版权音频即可生效）与默认免费档（`s2.1-pro-free`）的声学智能降级及生理韵律微调，撤除需要频繁抽卡制作的电影拟音（`sfx/`）、角色干声试听（`samples/`）、序幕离线母带（`prologues/`）与 Fish Plus 网页积分教程。

## 二、核心改动

1. **免费档声学智能降级与生理韵律调制（[`语音运行.py`](../../语音运行.py)）**：
   - 新增 `_degrade_drama3_for_s2()`，在 `s2.1-pro-free` / `s2.1-pro` 下将 `<whisper>/<soft>/<slow>/<fast>` 无损降级为 `[whispering]` / `[soft tone]` / `[slowly]` / `[speaking fast]`。
   - 升级 `_normalize_s2_chinese_aliases()`：扩充亲密气声/沙哑/发紧/发颤/羞耻短别名，并新增 `_S2_CN_KEYWORD_RULES` 自动从自由中文导演长句抽取英文控制词（避免 S2 漏读或忽略）。
   - `_prepare_tts_job()` 与 `_build_fish_payload()` 支持 `speed_scale`（`0.85–1.10`）与 `expressive_boost`（`0.0–0.12`），按实时高潮/欲望/体力态动态微调语速与表现力并隔离缓存键。
2. **本地循环背景音景服务（[`语音运行.py`](../../语音运行.py)）**：
   - 启动入口 `_ensure_audio_dirs()` 自动创建 `txt文件/audio/ambient/` 与防安卓媒体库扫描的 `.nomedia`。
   - `_serve_public_file()` 放行 `txt文件/audio/` 白名单音频后缀（`.mp3`/`.ogg`/`.opus`/`.wav`/`.m4a`/`.webm`），新增 `scan_audio_assets()` 与 `GET /api/audio_assets` 零配置自动发现 5 槽背景音（`calm_home` / `rain_night` / `tension_stealth` / `intimate_warm` / `aftermath_quiet`）。
3. **前端双轨交叉淡入背景音景、Audio Ducking 与生理韵律（[`voice_client.js`](../../voice_client.js)、[`story_client.js`](../../story_client.js)、[`story_client.css`](../../story_client.css)）**：
   - `VoiceClient` 导出 `getAudioAssets()`，`buildPayload()` 与 `prefetchBatch()` 透传 `speed_scale` / `expressive_boost`。
   - `story_client.js` 保留双 `<audio>` 轨平滑交叉淡入淡出背景音景 `syncAmbientSoundscape()`（按昼夜/警惕/亲密/余韵自动换曲）、TTS 播报自动压低背景音 `duckAmbient()`（压至 28%）、系统设定「本地背景音景」控制卡与动态生理韵律计算 `computeProsodyMod()`；移除所有拟音、角色原声试听按钮与离线序幕母带分支。
4. **本地音频目录保护（[`一键同步GitHub.py`](../../一键同步GitHub.py)、[`.gitignore`](../../.gitignore)）**：
   - 将 `txt文件/audio/` 加入 `LOCAL_ONLY_NESTED_DIRS` 与 `.gitignore`，确保增量同步与 `--prune` 绝不误删玩家本地背景音。
