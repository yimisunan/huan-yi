# 2026-11-26 · 人物「活人感」五支柱架构升级（去数值简报、分角色心智惯性层与建设性摩擦）

> **定位**：在不增加一次 LLM 调用、不破坏 Operit 2 `Zone 0/1` KV 缓存、严守《全局执行法典》卷零轨 A 主权红线的前提下，根治 AI 角色“RPG 查表感 / 客服迎合感 / 每幕情绪归零 / 多人同场围着主角转 / 转场 T-Pose 刷新”五大傀儡化根因。

---

## 一、核心背景与诊断

此前实测前台编译结果与上下文管道，定位出 5 个导致角色僵硬的核心结构性原因：
1. **前台直灌裸游戏数值与 RPG 词**：`compile_state_qualitative_brief()` 向前台输出 `好感82/羞耻100/堕落0`、重复 3 遍的 `被动Lv.0(凡人体质...)`、`好感天花板85未解锁` 与日常午宴冷态 `生理周期：危险期`，把演播模型拉进“查表算分”机械态。
2. **缺少分角色情绪惯性与主观记事账本**：`L1–L4` 仅存全局客观大事，`micro_states` 仅 3 个无原因布尔值，角色缺乏跨幕未散余绪（`mood`）、手头牵挂（`preoccupation`）与私下小疙瘩/惦记（`impressions`），导致每幕情绪归零。
3. **缺少显式反迎合与横向互动授权**：RLHF 惯性令角色倾向句句接圆、顺从圆场，且多人同场提示只覆盖段末选项，导致同场多角色排号只朝徐志北发言。
4. **入场缺少进行时生活余温**：`reconcile_offstage_presence()` 仅提供 `常住 / 周末在家` 等静态标签，切场景时人物像站桩等待指令。
5. **角色档案偏反应手册**：缺主动挑话习惯、压力防御战术/认知盲区与同场横向化学反应锚点。

## 二、五大支柱落地明细

### 支柱一：去数值化「导演心理简报」重构（`story_compiler.py`）
- 新增 `_heroine_affection_desc()`（按沈知韫 / 徐念薇 / 苏婉青性格差异化 6–7 档）、`_heroine_shame_desc()`（5 档边界感）、`_heroine_depravity_desc()`（`0` 彻底静默省略）、`_heroine_passive_desc()`（`Lv.0` 静默省略，`Lv.1~4` 翻译为具体洞察/合理化/倦怠/压迫演法）。
- 宿主体力/魅力/商业嗅觉在 Stage 1 前台转为纯心理与气场语言；`生理周期：危险期` 仅在亲密进行态、高欲（`≥45`）、低羞耻（`≤75`）或堕落（`≥15`）时按需注入；叠加 `aff_delta_last` 近期好感微趋势提示。
- 底层 `save_state.json`、前端属性面板与 `Stage 2` 结算模型 100% 保留精确数值不变。

### 支柱二：零额外调用「分角色心智与情绪惯性层 (`npc_mind`)」（纯暗箱不剧透前端）
- **`save_store.py`**：新增 `NPC_MIND_TARGETS = ('沈知韫', '苏婉青', '徐念薇', '徐承邺')` 与 `default_npc_mind()`，持久化进 `save_state.json['npc_mind']`（每角色含 `mood`、`mood_ttl`、`preoccupation`、`impressions[<=2]`、`aff_delta_last`），`normalize_state()` 对旧档自动补齐；同步刷新 `存档/save_state.json`，`存档清理器.py` 与 `存档开局随机盲盒.py` 自动继承开局初始牵挂。
- **`story_progression.py`**：
  - `_sanitize_director_echo()` 容错白名单解析可选 `mind_updates`（过滤非法角色与空/无效词，绝不抛 `RoundError`）。
  - 新增 `advance_npc_mind()` 接入提交事务原子落盘：每幕自动衰减 `mood_ttl`（默认 2 幕，跨夜或跨天立即清空瞬态情绪而保留 `preoccupation` 与 `impressions`），`impressions` 按在场/跨天衰减 `ttl=6` 且相似去重最多留 2 条，并按本轮真实好感变动维护 `aff_delta_last`。
- **`interaction_runtime.py` & `story_compiler.py`**：
  - 仅经后端 `effective_state` 透传至 `Zone 2`（`cast_mind` 仅包含当前在场 `cast`，不碰 `Zone 0/1` KV 缓存）与 `Stage 2`（规则 12 顺手摘录 `mind_updates` + `user_context.cast_mind`），**`ir.view()` 前端快照完全不暴露**，保持暗箱沉浸。

### 支柱三：「活人演法与建设性摩擦」协议（`叙事判断.json` + `story_compiler.py`）
- `txt文件/知识库/叙事判断.json`（`narrative.pace`）新增 5 条「活人演法与建设性摩擦（反傀儡铁律）」：GOTE 手头事进场、斜向回应与分寸拒绝（反客服迎合）、心智理论与合理误判（严禁读心看穿主角括号内心）、多人同场横向空气、留住生活毛边。
- `story_compiler.py` `build_user_delta()` 在 `len(cast) >= 2` 时显式注入 NPC-to-NPC 横向接话/眼神暗递提示，并在 `Zone 2` `output_format` 尾部嵌入正面「演法锚点」。

### 支柱四：「进场即中途（In Medias Res）」动态生活余温（`story_progression.py` + `story_compiler.py`）
- 新增纯 Python 零成本 `build_scene_entry_snapshot()`，覆盖 4 名核心角色 × 主要地点 × 4 时段（`morning/afternoon/evening/night`），并在对应角色 `offstage_clocks` 进度 `>= 2` 时自动关联暗钟主题余波。
- 仅在首幕或刚切场景（`scene_turns <= 1` 且非亲密进行态）注入 `Zone 2['scene_entry_residue']`，同场景第 2 幕起自动静默。

### 支柱五：四人「活人骨相」增厚与 Operit 世界书同步
