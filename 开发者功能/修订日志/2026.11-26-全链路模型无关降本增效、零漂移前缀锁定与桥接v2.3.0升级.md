# 2026-11-26 · 全链路模型无关降本增效、零漂移前缀锁定与桥接 v2.3.0 升级

> 对应架构方案：全链路模型无关降本增效改造（Batch 1 前缀锁定与宿主样板净化 + Batch 2 Zone 2 真差分去重与 Stage 2 结算瘦身 + Batch 3 热路径缓存/v2 `live.txt` 懒解耦/心跳退避 + 附项付费语音预热保护门禁）。

---

## 1. 背景与根因诊断

在 500 轮成熟长局实测中，既有 v2.2.0 架构虽已完成三区投影与 P3 三轨记忆存储，但仍存在六处与具体模型无关的纯工程冗余与缓存击穿点：

1. **Operit 2 宿主样板污染**：演播专用会话仍被宿主自动注入 `AGENTS.md`（`8,108` 字）及无关的「文件同步 / 附件 / 泛化助手介绍」样板，与游戏演播毫无关联且每轮占位。
2. **Zone 1 前缀高频击穿**：场外人物提及（`references`）与中段高欲/警惕状态跃迁直接混入 `Zone 1` 冻结前缀，单次场外提及即造成 `+831` 字漂移，击穿整段 `Zone 0 + Zone 1` 的隐式/显式 KV 缓存；同时更改语音或导演节奏等无关偏好也缺乏精确的 `prefs_epoch` 区分。
3. **Zone 2 同会话重复重传**：同会话第 2 轮起 `scoped_memory` 未对已注入锚点/情景幕做内容指纹去重，静态面板/亲密态势/已赠礼物/输出规范每轮整块重发，500 轮成熟档下 Turn 2 仍达 `4,002` 字。
4. **Stage 2 后台结算冗余与偶发机械重试**：`sys.*` 仍向结算副模型灌入纯 Python 后端算式表格，静态输出骨架与 `channels_enum` 塞在动态 `user_context` 中每轮重复发送（`5,021` 字）；空串可选字段、已有进行中任务时误发 `task` 或无害 `vigilance_events(target='徐承邺', tags=['无异常回合'])` 会触发整次 Stage 2 重试。
5. **运行时重复 I/O 与空转轮询**：每轮重复读取解析知识库/关系库/角色别名、`packet()` 对 v2 桥接仍无条件构建并落盘 `169.6 KB` 的 `live.txt`（耗时 `611.3 ms`），桥接 `monitor()` 每 6 秒高频请求 `/api/story/bridge-info` 与 `/api/story/worker/control`。
6. **付费语音预热缺乏静音与草稿门禁**：默认免费档（`s2.1-pro-free`）零费用无需改动，但若玩家切换付费档（`pro` / `drama`），静音状态或 Stage 1 流式半成品阶段仍会预热最多 3 句造成潜在额度浪费。

## 2. 核心变更明细

### 2.1 Batch 1：零漂移 KV 前缀锁定与 Operit 2 宿主样板净化
- **Operit 2 宿主样板精准净化（`scene_chat_dev/local.story.operit_bridge/main.js` / `ui/settings.ui.js`）**：
  - 新增 `sanitizeOperitCorePrompt(prompt, enabled)`，**仅作用于 `state.role === 'live'` 的正式演播专用会话**，自动剥离 `<workspace_rule_file>`（含 `AGENTS.md`）、`包系统 / PACKAGE SYSTEM`、`文件同步 / FILE SYNC`、`附件 / ATTACHMENTS` 及 Operit 泛化介绍段，完整保留工作区路径与只读工具指引（内置不变式防御回退）；100% 不触碰 `scene_chat` 及用户普通聊天。
  - 新增 `sanitizeOperitBoilerplate` 持久化配置（默认 `true`），在 Operit 设置页「高级连接与模型」卡片提供即时开关。
- **Zone 1 100% 字节级冻结 + 无损场外简报下沉（`story_compiler.py` / `interaction_runtime.py`）**：
  - `build_zone1_scene()` 新增 `frozen_flags`，`material_delivery_v2()` 固定传 `references=()` 与会话首轮冻结的 `zone1_flags = {vig, intl}`，确保同场景多轮 `Zone 1` 0 字节漂移。
  - 新增 `compile_relationships_delta()` 与 `_load_vigilance_body()`：首次提及场外角色时通过 Zone 2 `referenced_offstage` 一次性下发**完整** `compile_characters` 人设 + 双向称谓锁 + 场外禁演护栏，同会话后续轮自动折叠为极简 `referenced_offstage_active`；中段首次触发高欲/警惕规则时通过 `vigilance_craft_guide` / `intimate_craft_guide` 单次下发。
  - `session_meta`（`zone1_flags` / `injected_refs` / `injected_guides` / `memory_fps` / `state_hashes`）严格遵循 **commit-only** 持久化纪律：仅在后端确认 `status === 'committed'` 后写入 `config.liveSession`，失败或被拒绝不污染状态。
- **精确 `prefs_epoch` 重卷（`story_service.py` / `main.js`）**：
  - 新增 `StoryService._prefs_epoch()` 仅哈希影响 `Zone 0` 的偏好字段（`protagonist_style`、`custom_rules_*`），通过 `claim()` 下发至桥接 `liveSession()`；修改语音静音、导演节奏或开窗回溯模式不再误触发会话重卷。

### 2.2 Batch 2：Zone 2 真差分去重、开窗回溯模式与 Stage 2 结算瘦身
- **三轨记忆内容指纹去重（`save_store.py`）**：
  - `retrieve_memory_view()` 新增 `exclude_fingerprints` 参数并返回 `selected_fingerprints`（格式 `id:sha8` 内容哈希）：同会话后续轮自动跳过未变化的锚点/情景幕/编年史，**永不跳过 `NOW`（`pending_buffer`）**；一旦锚点被 `anchor_ops.update` 修订，内容哈希变化即自动重新注入；`K01` 与房间级 `known_by` 隔离 100% 保持不变；`active_anchors_index` 扩展至全量 `MAX_ACTIVE_ANCHORS = 24`（优先保留 `importance >= 4` 与同场相关锚点）。
- **Zone 2 真差分、回溯门控与 `anchor_history_mode`（`story_compiler.py` / `interaction_runtime.py` / `story_client.js`）**：
  - `build_user_delta()` 新增 `prev_state_hashes` 状态真差分（面板/亲密态/道具/已赠礼/暗箱心智未变化时折叠为 `unchanged_from_prev_turn`）、Turn 2+ 按回溯关键词门控 `optional_archive_lookup`、精简 Turn 2+ `output_format`（保留紧凑 `[D:徐志北]` 发言锁）。
  - 新增 `anchor_history_mode`（默认 **`balanced`**：开窗首轮末 2 轮 100% 原文保留 + 最多 2 轮在 6,000 字软预算内保留；可在前端剧场「阅读与体验」一键切回 **`full`** 完整 6 轮）。`maxTurnsPerSession` 保持默认 **`10`**，并在 `ui/settings.ui.js` 补充强/弱模型调优建议。
- **Stage 2 后台结算瘦身与机械预清洗（`story_compiler.py` / `interaction_runtime.py`）**：
  - `_strip_kb_noise(..., mode='settlement')` 精准剔除 `sys.*` 中的纯 Python 后端算式与分段公式表，**100% 保留全部 12 项核心 AI 打标触发条件**（`羞耻>75` / `主动破锁_30阶梯` / `苏婉青_真相揭露` / `触发高潮_绝顶清算` / `自慰_暗中纾解` / `解离保护` / `外地` 感知门禁 / `内射` / `effective_progress` / `优雅掌控_魅力精进` / `确诊怀孕` / `体力 ≤ 15`）。
  - `build_settlement_spec()` 将静态 JSON 输出骨架与 `channels_enum` 移入可跨轮缓存的静态 `system_prompt`，动态 `user_context` 改为无损单行 `active_anchors`（`_format_anchors_compact_lossless()`，零正文截断）、精简 `intimate`/条件 `items`、活跃任务存在时省略 `task_whitelist_current`、去除重复 `output_contract`。
  - `normalize_dual_stage()` 前置 `_sanitize_settlement_mechanical_noise()`，仅清洗无歧义机械噪声（空串可选字段转 `None`、清除 `fallback_decision.options` 空 `operation`、清除 `SYSTEM` 或已有未完成任务时误填的 `resolution.task`、剔除严格无害的 `vigilance_events(target='徐承邺', tags=['无异常回合'])`），真实越权监视标签仍保留给严格校验器拦截重试。

### 2.3 Batch 3：热路径缓存、v2 `live.txt` 懒解耦、心跳退避与付费语音门禁
- **热路径 `(mtime_ns, size)` 线程安全缓存**：
  - `story_compiler.py`（`_load_kb_entries`、`compile_event_catalog`、`compile_codex_runtime`、`build_zone0_global` 基座、`build_settlement_spec` 静态基座，并复用 `reg.verify_view()[1:]` 消除重复 jsonl 解析）、`relationship_query.py`（`RelationshipRegistry` 注册表与 `verify_view` 缓存，并经 `relationship_query.py render` 同步刷新 `txt文件/关系称谓查询.jsonl`）、`scene_chat.py`（角色别名表缓存）与 `interaction_runtime.py`（`_cached_digest` 静态源哈希缓存）。任意文件改动即刻自动失效。
- **v2 懒跳过 170 KB `live.txt`（`interaction_runtime.py` / `story_progression.py`）**：
  - 新增 `_is_v2_bridge_active(tasks)` 检测活跃 `2.x` 桥接心跳，`sp.create()` 自动向 `ir.packet(..., lazy_live_txt=True)` 放行懒模式：跳过构造与原子写入 170 KB `live.txt`，改在 `.context.json` 保存约 `2.1 KB` 的 `v2_packet_meta`；`material_delivery_v2()` 与 `verify()` / `verify_delivery()` 仍对真实 `存档/全局记忆库.txt` 与 `txt文件/互动运行配置.json` 执行 SHA-256 防篡改核验；v1 桥接路径 100% 兼容不变。
- **桥接 `monitor()` Token 缓存与 6s/30s 空闲退避（`main.js` / `story_service.py`）**：
  - `main.js` 新增 `getBridgeToken()`（进程内复用，遇 `401/403` 或 `service_epoch` 变化自动失效重取）与自适应 `scheduleMonitor()`（活跃期 6s，空闲 >60s 自动退避至 30s；Node 测试环境调用 `.unref()` 避免事件循环保活）；后端 `story_service._bridge_view()` 放宽存活窗至 `45s` 并结合 `worker_wait()` 内存级 `_last_worker_wait_at`（40s），零额外写盘且空闲永不误报离线。
- **附项·付费语音预热保护门禁（`story_service.py` / `story_client.js`）**：
  - `StoryService._trigger_tts_prewarm(..., stage=...)` **保持默认免费档（`voice_tier: "free"`）100% 原样不变**；仅当切换至付费档（`pro` / `drama` 等）时：静音（`voice_playback_enabled=False`）直接跳过预热、跳过 `streaming` 阶段待 `settling` 稳态后再预热、并将预热句数上限收敛至 2 句；前端 `toggleVoice()` 及重听解静音非阻塞同步 `voice_playback_enabled` 至 `/api/story/preferences`（不影响 `_prefs_epoch`）。
- **统一升版打包 `2.3.0`**：同步更新 `manifest.json`、`main.js`（`PLUGIN_VERSION='2.3.0'`）、`ui/settings.ui.js`、`README.md` 与 `.gitignore`，执行 `python3 scene_chat_dev/build.py` 生成 `scene_chat_dev/artifacts/故事桥接-continuous-2.3.0.toolpkg`（53 KB）并自动清退旧 `2.2.0.toolpkg`。
