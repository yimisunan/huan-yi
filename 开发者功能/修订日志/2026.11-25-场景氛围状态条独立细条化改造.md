# 2026-11-25 场景氛围状态条独立细条化改造

> 范围：正式剧场前端布局与样式（`main_template.html`、`story_client.css`）。

## 1. 问题背景

原实现将场景氛围状态胶囊容器 `#sceneAtmospherePills`（用于实时呈现细分子地点、空间私密性、亲密慢燃拍数、衣着/痕迹与同场暗流）置于可滚动正文容器 `<main id="stream">` 内部，并以 `position: sticky; top: 6px;` + 全宽圆角浮条展示。玩家在移动端或桌面端上下滑动阅读时，该浮条持续悬停覆盖在剧情正文上方并造成遮字。

## 2. 核心改动

1. **DOM 结构迁出滚动区（`main_template.html`）**
   - 将 `<div id="sceneAtmospherePills" class="scene-atmosphere-pills" hidden aria-live="polite"></div>` 从 `<main id="stream">` 内部移至 `<main id="stream">` 正上方，作为 `.layout` 的独立子块。
   - 彻底消除正文滚动时的浮层遮挡，同时避免点击状态条误触 `#stream` 的逐句演播推进事件。

2. **极窄贴顶细条样式（`story_client.css`）**
   - 移除 `position: sticky; top: 6px;` 与大圆角悬浮胶囊外框，改为 `flex: 0 0 auto` 通栏极窄细条（深色与 `ivory` 象牙白双主题同步适配，无标签时 `[hidden]` 零占位）。
   - 采用单行不折行（`flex-wrap: nowrap`）+ 首尾 `margin: auto` 居中 + 溢出横向静默滚动（`overflow-x: auto`），确保多标签同时激活时仍维持单行紧凑高度、不挤占正文阅读区。

3. **桌面宽屏网格行对齐（`story_client.css`，`@media (min-width: 860px)`）**
   - `.layout` 网格行更新为 `grid-template-rows: auto minmax(0, 1fr) auto auto`。
   - `.scene-info` 侧边栏跨行调整为 `grid-row: 1 / 5`；右侧依次排布 `.scene-atmosphere-pills`（第 1 行）、`#stream`（第 2 行）、`.settlement-float`（第 3 行）、`#composer`（第 4 行）。

## 3. 验证

- 校验 `main_template.html` 中 `#sceneAtmospherePills` 唯一且位于 `<main id="stream">` 之前。
- 校验 `story_client.css` 花括号配平与双主题/双端断点规则无冲突。
