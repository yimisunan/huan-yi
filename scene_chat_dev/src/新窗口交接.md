## 找到正确工作区

文件工具与终端均以绑定工作区 `.` 为基准。Android 终端默认路径为 `/storage/emulated/0/互动对话项目/Gemini网页版`（真实解析可能显示 `/sdcard/互动对话项目/Gemini网页版`）。Operit 工作区 VFS UUID 由当前设备动态分配，请勿硬编码。

终端每次先运行 pwd、进入 `.` 并核对 AGENTS.md、story_service.py，进入失败就停止，不在主目录继续。文件与附件使用相对路径；不要搜索整台设备找项目，也不要把 VFS 绝对路径当终端路径。

本项目续作在 scene_chat_dev 下按 plan/step_N.md 与 logs/step_N.md 配对记录。清理为 step_29，下一项新维护使用 step_30。临时材料只放 scene_chat_dev/tmp，收尾清空；源码维护遵循 into，落盘遵循任务五步走。

## 当前运行现场

Python 启动入口是根目录“语音运行.py”，本地地址为 http://127.0.0.1:5000。Operit 故事桥接插件 ID 为 `local.story.operit_bridge`，子包 `story_bridge`，当前版本 **2.3.3**，API 2.0.0。设备安装区为 `/operitapp/data/extensions/device/packages/故事桥接.toolpkg`（日常源码维护勿直接改它）。源码唯一维护入口为 `scene_chat_dev/local.story.operit_bridge/`，唯一保留成品为 `scene_chat_dev/artifacts/故事桥接-continuous-2.3.3.toolpkg`，构建入口是 `scene_chat_dev/build.py`。

Fish API 密钥从启动进程的 `FISH_API_KEY` 环境变量读取，不保存在仓库源码。修改 Python 需停止并重新运行“语音运行.py”；前端改动后刷新页面；插件改动须构建并同 ID 导入。不要把旧桥接目录当维护入口。

## 已完成修复和当前行为

step_25 到 step_28 的维修均已完成源码、定向验收、同 ID 安装及 main 推送；用户在 1.9.1 后明确表示“可以了”。不要再把旧记录中“等待重启或实测”当成当前待办。

- 合法空字符串只在明确允许路径转成内部 null，仍拒绝缺值、残缺 JSON 和重复关键字段，不推测缺失语义。
- 正式读取工具白名单统一；搜索仅定位，不当作正文覆盖。按本次 packet 范围真实分段读取，默认按约 9000 字符/24000 UTF-8 字节规划，平台不返回纯尾空白不再误拒绝，非空正文继续严格校验。真正缺页可在同任务、同会话、同租约补读一次。
- 默认会话策略 continuous，持续沿用，不再累计 120000 字符自动换窗。可选择 service_restart（Python 服务 epoch 改变时新建）、per_action（每个新 request_id 新建，同编号重试沿用），空闲时可手动重建并保留旧聊天。更换模型、工作区或存档会隔离会话；持续沿用不保证模型拥有无限上下文。
- 每个行动和重试仍读取当前正式 packet。上次校验错误传入重试信封和资料包；旧聊天不替代存档，失败内容不升级为事实。
- 付费 action 的 resolution.conditions 必须是完整对象，含 intensity、effective_progress、scene、npc、action_changed、stress_signals、breakout_triggered；无 NPC 时只有 npc 可空。SYSTEM 条件可空，契约按预扣 kind 动态生成。澄清或未移动也不能用空串代替付费条件。
- 地点别名由 txt文件/互动运行配置.json 唯一登记，服务与执行器共用 travel_intent。“家、家里、家中、主宅、徐家”解析至徐家主宅，“公寓”解析至市中心顶层公寓。只接受明确当下移动指令；否定、未来、疑问、条件、二选一、多目的地不自动执行。模型收到解析后的操作和玩家原文依据。

正式首页保留电脑端更新后的 UI，逐节点演播后才出现段末 A/B/C 与自定义。A/B/C 消耗 5/10/15，自定义先扣 15，再按真实结算退回差额；低体力按最终费用判断。游戏时钟跨零点和体力不足触发记忆回合处理，整夜安稳休息恢复至最大体力，零点本身不回血。用户存档已有推进，不得用旧快照回灌。

记忆保留必要事实，可无新增 fact。P3 三轨记忆存储于 `存档/memory_store.json`（永久锚点 `anchors`、近期情景幕 `episodes` + 缓冲、分视角编年史 `chronicle`），滚动保留最新 16 幕原文。权威参数见 `txt文件/互动运行配置.json`，勿在交接中维护第二份参数源。
