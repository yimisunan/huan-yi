- 合法空字符串只在明确允许路径转成内部 null，仍拒绝缺值、残缺 JSON 和重复关键字段，不推测缺失语义。
- 正式读取工具白名单统一；搜索仅定位，不当作正文覆盖。按本次 packet 范围真实分段读取，默认按约 9000 字符/24000 UTF-8 字节规划，平台不返回纯尾空白不再误拒绝，非空正文继续严格校验。真正缺页可在同任务、同会话、同租约补读一次。
- 默认会话策略 continuous，持续沿用，不再累计 120000 字符自动换窗。可选择 service_restart（Python 服务 epoch 改变时新建）、per_action（每个新 request_id 新建，同编号重试沿用），空闲时可手动重建并保留旧聊天。更换模型、工作区或存档会隔离会话；持续沿用不保证模型拥有无限上下文。
- 每个行动和重试仍读取当前正式 packet。上次校验错误传入重试信封和资料包；旧聊天不替代存档，失败内容不升级为事实。
