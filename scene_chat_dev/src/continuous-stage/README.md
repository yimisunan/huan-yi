# 此刻在场 · 连续叙事原型

启动：在项目根目录运行 `python scene_chat_dev/src/continuous-stage/serve.py`，打开 http://127.0.0.1:8766 。当前开发会话已启动该服务，关闭终端会话或应用结束后需重新启动。现役5000服务不需要重启。

建议体验：点击A看多人接话 → 点击B看行动范围与消耗 → 确认出发看场景推进 → 打开“本段记录”整理并查看历史。演示控制可直接进入继承权分支、模拟失败重试、切换纯阅读和重置。常驻输入支持自定义文本与Ctrl/Command+Enter发送。

三张fullbody原图作为共同现场的人物层，说话者凸显；手机文字覆盖人物下半身。点击人物入口或对白姓名查看外出/居家/into原图。人物位置不等于私聊对象，所有交流共用一条记录。原图约10MB/张，首次加载较慢，未修改或复制原图。

这是预写分支演示。自由输入用关键词进入有限分支，其余显示预写承接；它不证明模型能判定任意行动。交流12、行动6、单次交流1、调查2均为演示数字，不是正式规则。演示状态只存当前浏览器localStorage专用键`abyss-continuous-stage-demo-1`。阶段归档保留确认事项；重置会清除此演示状态。

不请求模型/TTS，不读写正式存档。独立服务器仅开放三个页面资源与三位角色指定图片，不开放项目目录或配置。手机/桌面尺寸使用同源iframe检查；Workspace Browser不支持真实视口resize，真机软键盘、视觉截图验收及辅助技术朗读尚未完成。

回退：关闭独立8766服务并删除本原型目录即可，不影响现役入口。

三版聊天对比入口：http://127.0.0.1:8766/compare.html ，A在场书页、B同席聊天、C此刻对话。每版相同短句演示，自由输入、逐条到达、显式回到初始、手动恢复。旧行动版仍在/index.html。当前演示不自动恢复旧记录；A/B/C是方案编号，不是剧情行动选项。


方案B支持旁白、人物动作与对白顺序混排。打开 http://127.0.0.1:8766/compare.html#b ，点击“播放混合示例”，或连续发送“今天忙吗？”和“问问大家”。旁白无头像/气泡，用细线与独立正文；动作在人物名下横向显示，使用无气泡竖线段；对白保留聊天气泡。聊天记录同样呈现。回到初始可重播示例，示例不计玩家发送句数。
